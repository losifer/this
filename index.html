Vocabulary

One body, nine expressions — the alphabet the agent uses.

  • COMMA

    Rest / Idle / Streaming

    The default resting state. Eyes relaxed, body neutral.

  • BLINK

    Ack / Listening

    A brief close-and-open. Signals the agent heard you.

  • DOT

    Alert / Thinking / Tool call

    Focused dot pupils. The agent is processing.

  • SQUINT

    Scan / Searching / Reading

    Narrowed eyes. The agent is reading or scanning content.

  • HAPPY

    Success / Found / Resolved

    Upturned eyes. Something went well.

  • WOW

    Attention / Asking / Needs input

    Wide eyes, body shifts gold. The agent needs you.

  • WINK

    Closed / Done / Delivered

    One eye shut. Task complete, signing off.

  • HEART

    Love / Pinned / Saved

    Heart-shaped eyes. Something was saved or favorited.

  • XX

    Failed / Error / Cancelled

    Crossed-out eyes. Something went wrong.

In practice: the session thread

The session thread choreographs every AI reply around Olly, whose eyes change with each state.

Why is checkout latency spiking?

Can you roll back that deploy?

Ask Olly anything…
  1. 01

    Olly pulsates

    Olly pops in beside the reply and pulses for a 2s beat before any text: an acknowledgement that the answer is coming.

    blink

  2. 02

    Text streams

    The reply streams in character by character next to Olly, who stays attentive while speaking.

    dot

  3. 03

    Response complete

    Olly repositions below the text and winks for 600ms, then rests in the blink-heavy idle cycle. Hover shows a tooltip; a press squishes.

    wink → idle · hover happy · press heart
